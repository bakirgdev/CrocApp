# Doprinos

Dokumentacija za saradnike i interna dokumentacija nalaze se u repozitoriju, ne na ovom sajtu, jer moraju pratiti kod tačno onako kako se mijenja. Ovaj sajt pokriva korištenje aplikacije; repozitorij pokriva njeno građenje i mijenjanje.

- [`CONTRIBUTING.md`](https://github.com/bakirgdev/CrocApp/blob/main/CONTRIBUTING.md): postavljanje, grane, commit-ovi, stil, verifikacija, tok pull requestova
- [`CODE_OF_CONDUCT.md`](https://github.com/bakirgdev/CrocApp/blob/main/CODE_OF_CONDUCT.md): Contributor Covenant 3.0
- [`SECURITY.md`](https://github.com/bakirgdev/CrocApp/blob/main/SECURITY.md): opseg i privatno prijavljivanje ranjivosti
- [`docs/ARCHITECTURE.md`](https://github.com/bakirgdev/CrocApp/blob/main/docs/ARCHITECTURE.md): mapa sistema, slojevi, tok događaja
- [`docs/BUILDING.md`](https://github.com/bakirgdev/CrocApp/blob/main/docs/BUILDING.md): tačan alatni lanac, koraci za svježi klon, harnesi za verifikaciju
- [`docs/GLOSSARY.md`](https://github.com/bakirgdev/CrocApp/blob/main/docs/GLOSSARY.md): potpuni rječnik pojmova za saradnike i internu upotrebu
- [Šabloni za prijave](https://github.com/bakirgdev/CrocApp/tree/main/.github/ISSUE_TEMPLATE): gdje prijaviti greške, funkcije i druge izvještaje

Pull requestovi su dobrodošli: greške, funkcije, dokumentacija, dizajn, landing stranica. Počnite sa `CONTRIBUTING.md` iznad.
