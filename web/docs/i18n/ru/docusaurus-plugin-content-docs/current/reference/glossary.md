# Глоссарий

| Термин | Значение |
|---|---|
| Кодовая фраза / секрет | Строка вида `NNNN-word-word-word`, которую обе стороны используют, чтобы найти друг друга и получить сеансовый ключ. Собственные коды содержат не менее 6 символов. |
| PAKE | Password-Authenticated Key Exchange (аутентификация по паролю с обменом ключами). Превращает слабую кодовую фразу в сильный ключ шифрования так, что релей его никогда не узнаёт. |
| Релей | Сервер, к которому подключаются обе стороны, когда прямой локальный путь недоступен. Видит только зашифрованный текст, никогда — ключ. |
| Комната (Room) | Канал встречи на релее, производный от первых 4 символов кодовой фразы. Два кода с одинаковыми этими символами могут столкнуться в одной комнате. |
| Кривая (Curve) | Эллиптическая кривая, по которой работает PAKE. CrocApp использует значение по умолчанию из croc. |
| Алгоритм хеширования | Проверка целостности, используемая для переданных файлов. |
| Обнаружение узлов в локальной сети (LAN peer discovery) | Механизм, позволяющий передачам в одной сети полностью обходить релей; не гарантированно работает в любой сети. |
| Только локальная сеть (Local-only) | Настройка, которая заставляет передачу оставаться в локальной сети, отказываясь от релея, если прямой путь недоступен. |
| Сжатие | Данные файла по умолчанию сжимаются при передаче; это можно отключить. |
| Значок доверия | Индикатор на экране, показывающий, что передача защищена сквозным шифрованием, и какой путь релея используется. |
| История передач | Локальный, хранящийся только на устройстве журнал прошлых передач CrocApp. |

Полный глоссарий для участников разработки и внутреннего устройства (внутреннее устройство протокола croc, мост Go/gomobile, архитектура приложения и соглашения репозитория) см. в [`docs/GLOSSARY.md`](https://github.com/bakirgdev/CrocApp/blob/main/docs/GLOSSARY.md) на GitHub.
