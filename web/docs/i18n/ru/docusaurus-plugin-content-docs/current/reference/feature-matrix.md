# Таблица возможностей

Номера возможностей (`F1`…) — стабильные идентификаторы, используемые по всему проекту. "Реализовано" означает, что возможность существует и работает в приложении уже сегодня; проект пока не выпустил сборку (см. [Установка](../getting-started/install.md)).

## Базовые (реализовано)

| # | Возможность | Флаг croc / происхождение |
|---|---|---|
| F1 | Отправка файлов (несколько) | позиционные аргументы, перетаскивание + средство выбора файлов |
| F2 | Отправка папок | позиционные аргументы |
| F3 | Отправка текста/буфера обмена | `--text` |
| F4 | Приём по коду | позиционные аргументы |
| F5 | Собственная кодовая фраза (мин. 6 символов) | `--code` |
| F6 | Показ QR при отправке + сканирование QR при приёме | `--qrcode` + нативный интерфейс |
| F7 | Выбор папки назначения; по умолчанию на iOS — папка приложения, видимая в Files | `--out` |
| F8 | Обработка перезаписи/возобновления через листы подтверждения | `--overwrite` + возобновление |
| F9 | Предпросмотр списка входящих файлов + принять/отклонить | эквивалент интерактивного запроса |
| F10 | Прогресс, скорость, отмена; Live Activity на iOS | опрашивается из движка |
| F11 | Автоматический выбор между локальной сетью и релеем | по умолчанию в croc |
| F12 | История передач (только локально) | нативный интерфейс |

## Расширенные настройки (реализовано)

| # | Возможность | Флаг croc |
|---|---|---|
| F13 | Собственный релей + пароль + IPv6 | `--relay --relay6 --pass` |
| F14 | Принудительно только локальная сеть | `--local` |
| F15 | Отключение сжатия | `--no-compress` |
| F16 | Архивация папки перед отправкой | `--zip` |
| F17 | Исключающие шаблоны / учёт `.gitignore` | `--exclude --git` |
| F18 | Переключатель автоприёма (выключен по умолчанию, показывается предупреждение) | `--yes` |
| F19 | Подтверждение с обеих сторон | `--ask` |

## Нативный интерфейс (реализовано)

| # | Возможность | Статус |
|---|---|---|
| F30 | Расширение "Поделиться" (отправка из любого приложения) | реализовано, только iOS |
| F36 | Интерфейс доверия: значок сквозного шифрования, "как это работает", индикатор активного релея | реализовано |

|---|---|---|
