# Совместимость с croc CLI

CrocApp встраивает **croc v10.5.0** как Go-библиотеку (через собранный `gomobile` фреймворк), а не вызывает бинарник `croc` через shell. Это значит, что приложение использует точно такой же протокол, как и CLI, в обе стороны.

:::note
После фиксации этой версии в апстриме croc вышла v10.6.0; CrocApp пока на неё не перешёл.
:::

## Пример: CLI отправляет, приложение принимает

На ноутбуке, используя croc CLI:

```bash
croc send file.txt
# -> prints something like 9822-word-word-word
```

На телефоне или Mac откройте **Receive** в CrocApp и введите выведенный код. Файл придёт точно так же, как если бы отправитель тоже использовал CrocApp.

## Пример: приложение отправляет, CLI принимает

Начните отправку в CrocApp, получите отображаемую кодовую фразу, затем на другой машине:

```bash
croc 9822-word-word-word
```

## Собственный релей

Обе стороны должны согласовать один и тот же релей. Из CLI:

```bash
croc --relay myserver:9009 send file.txt
```

В CrocApp укажите тот же адрес в разделе [расширенной настройки релея](../guide/power-options.md).

| # | Возможность | Флаг croc / происхождение |
|---|---|---|
| F1 | Отправка файлов (несколько) | позиционные аргументы |
| F2 | Отправка папок | позиционные аргументы |
| F3 | Отправка текста/буфера обмена | `--text` |
| F4 | Приём по коду | позиционные аргументы |
| F5 | Собственная кодовая фраза (мин. 6 символов) | `--code` |
| F6 | Показ QR при отправке / сканирование при приёме | `--qrcode` |
| F7 | Выбор папки назначения | `--out` |
| F8 | Обработка перезаписи/возобновления | `--overwrite` |
| F9 | Предпросмотр списка входящих файлов, принять/отклонить | интерактивный запрос |
| F10 | Прогресс, скорость, отмена | — |
| F11 | Автоматический выбор между локальной сетью и релеем | по умолчанию в croc |
| F12 | История передач | — |
| F13 | Собственный релей, пароль, IPv6 | `--relay --relay6 --pass` |
| F14 | Принудительно только локальная сеть | `--local` |

| F18 | Переключатель автоприёма | `--yes` |
| F19 | Подтверждение с обеих сторон | `--ask` |

## Совместимость версий и релеев

Поскольку CrocApp использует собственный библиотечный код croc, а не переписывает протокол заново, совместимость релея и протокола зависит от того, что поддерживает сам croc в зафиксированной версии. Использование достаточно свежей, не устаревшей версии CLI `croc` на другой стороне — самый безопасный вариант.
