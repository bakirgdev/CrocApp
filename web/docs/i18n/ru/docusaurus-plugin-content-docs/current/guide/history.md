# История (F12)

CrocApp хранит локальный список прошлых передач, доступный по значку истории на главном экране. Он никогда не покидает устройство: нет ни синхронизации, ни экспорта, ни участия сервера.

## Что записывается

Для каждой завершённой или неудавшейся передачи:

- Направление (отправлено или получено) и была ли это текстовая передача
- До 20 имён файлов
- Общее число файлов и общий размер
- **Подсказка кода**: только первый сегмент кодовой фразы (например, "7291-…"), никогда полная фраза
- Дата и статус (завершено, ошибка, отменено или отклонено)
- Для отправок — набор файловых закладок, используемых для поддержки **Send Again**: сохраняется по принципу "всё или ничего", не более 200 элементов; запись без закладок просто не предлагает Send Again

## Что никогда не записывается

- Содержимое файлов
- Полная кодовая фраза — только подсказка по первому сегменту
- Всё, что превышает ограничения в 20 имён и 200 закладок

## Send Again

Для прошлой отправки контекстное меню записи истории (или свайп-действие на iOS) предлагает **Send Again**, если для неё были сохранены закладки. Это заново подставляет те же файлы в новую отправку. Если исходные файлы с тех пор были перемещены или удалены, CrocApp сообщает, что они больше недоступны, вместо того чтобы молча ничего не отправить.

## Очистка истории

Нажмите **Clear** на панели инструментов экрана истории, затем подтвердите. Это удаляет только список — файлы, которые вы уже получили, остаются точно там, где были сохранены.
