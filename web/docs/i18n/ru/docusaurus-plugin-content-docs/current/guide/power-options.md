# Расширенные настройки

![Настройки CrocApp на iOS с расширенными параметрами на экране настроек](/img/screenshots/ios-settings-light.png#gh-light-mode-only)![Настройки CrocApp на iOS с расширенными параметрами на экране настроек](/img/screenshots/ios-settings-dark.png#gh-dark-mode-only)

CrocApp предоставляет набор расширенных настроек с разумными значениями по умолчанию. На macOS они находятся в окне настроек (⌘,); на iOS — на экране настроек, открываемом с домашней панели инструментов. Все семь ниже уже реализованы.

| # | Настройка | Элемент управления | Эквивалент в croc |
|---|---|---|---|
| F13 | Собственный релей, пароль, IPv6 | Поля **Address**, **IPv6 address**, **Password** в разделе Relay | `--relay --relay6 --pass` |
| F14 | Принудительно только локальные передачи | Переключатель **Local network only** | `--local` |
| F15 | Отключить сжатие | Переключатель **Disable compression** | `--no-compress` |
| F16 | Заархивировать папку перед отправкой | Переключатель **Zip folders before sending** | `--zip` |
| F17 | Исключающие шаблоны, учёт `.gitignore` | Поле **Patterns, one per line**, переключатель **Respect .gitignore** | `--exclude --git` |
| F18 | Автоприём входящих, выключен по умолчанию | Переключатель **Auto-accept incoming files** | `--yes` |
| F19 | Требовать подтверждения с обеих сторон | Переключатель **Confirm on both sides** | `--ask` |

## Релей (F13)

Поля **Address** и **IPv6 address** показывают значения croc по умолчанию в качестве текста-подсказки; оставьте их пустыми, чтобы использовать релей croc по умолчанию. Оставьте **Password** пустым, чтобы использовать пароль релея по умолчанию.

## Только локальная сеть (F14)

Когда включено, передачи никогда не обращаются к релею в интернете — CrocApp использует только локальную сеть. Если прямое локальное соединение установить не удаётся, передача завершается ошибкой, а не переключается на релей.

## Исключающие шаблоны (F17)

Шаблоны указываются по одному на строку в поле **Patterns, one per line**. **Respect .gitignore** дополнительно исключает всё, что исключил бы ваш `.gitignore`.

## Автоприём (F18)

Автоприём по умолчанию выключен. При включении CrocApp показывает такое предупреждение: "Files from anyone who has your code are saved without preview or confirmation. Unsafe file names still cancel the transfer. Both-sides confirm overrides auto-accept." При выключении: "Auto-accept skips the incoming-files preview. Leave it off unless you fully trust the sender."

## Подтверждение с обеих сторон (F19)

Когда включено, отправитель также должен одобрить передачу (через запрос **Receiver connected**), прежде чем она начнётся, в дополнение к обычному шагу принятия у получателя.

## Пока не реализовано

Дополнительный набор возможностей croc (прокси SOCKS5/Tor, HTTP-прокси, ограничение скорости отправки, выбор кривой и алгоритма хеширования, прямое подключение по IP, собственный мультикаст-адрес, настройка портов/количества передач, встроенный DNS-резолвер и запуск собственного релея из приложения для Mac) запланирован на более позднюю версию, но разработка ещё не начата.
