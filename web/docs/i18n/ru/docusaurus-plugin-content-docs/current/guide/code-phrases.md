# Кодовые фразы

Кодовая фраза выглядит так: `8412-mirage-cobalt-fresco` — короткий PIN, за которым следуют несколько слов. Она генерируется заново для каждой передачи, если вы не задали собственную на [экране отправки](sending.md).

## Она одновременно адрес и пароль

Ввода кода на другом устройстве достаточно — это одновременно и способ, которым два устройства находят друг друга, и секрет, который защищает передачу. Больше ничего настраивать для обычной передачи не нужно.

## Как это защищает передачу

Оба устройства выполняют **PAKE** (аутентификацию по паролю с обменом ключами) по кодовой фразе, чтобы превратить её в сильный ключ шифрования:

- Сам код никогда не передаётся по сети в открытом виде.
- Неверный код сразу приводит к ошибке, до того как начнётся передача каких-либо данных файла.
- Всё шифруется на отправляющем устройстве и расшифровывается только на принимающем; ничто посередине не может это прочитать.

## Одноразовость и истечение срока действия

Каждая передача использует одноразовую кодовую фразу. Тот, у кого есть код, считается партнёром по этой передаче, и код истекает вместе с ней — повторно использовать его для следующей передачи нельзя.

## Как поделиться: QR-код и вставка

CrocApp показывает код и как текст, и как QR-код (F6). Содержимое QR-кода — `croc://<code>`, поэтому его сканирование работает и с другими инструментами, понимающими ту же форму диплинка.

Чтобы ввести код в поле **Receive**, есть два явных способа: использовать кнопку **Paste** или (на iOS) нажать **Scan QR Code**. CrocApp не читает буфер обмена незаметно; вставка — это всегда действие, которое вы инициируете сами. Вставленный или отсканированный текст может содержать префикс `croc://` или быть просто кодом — оба варианта принимаются, если оставшаяся часть содержит не менее 6 символов без пробелов.

## Собственные коды

Собственный код должен содержать не менее 6 символов. Задайте его в поле **Custom code** на экране отправки, чтобы поделиться им через канал, которому вы уже доверяете (телефонный звонок, уже существующий зашифрованный чат), вместо того чтобы полагаться на сгенерированный.

## Безопасный обмен кодом

Делитесь им через доверенный канал, так же как вы бы поделились одноразовым паролем: произнесите его, отправьте через уже доверенный чат или дайте получателю отсканировать QR-код прямо с вашего экрана. Поскольку код одновременно и адрес, и пароль, любой, кто получит его до завершения передачи, сможет к ней присоединиться.
