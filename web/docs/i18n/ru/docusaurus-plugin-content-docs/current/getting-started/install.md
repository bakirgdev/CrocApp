# Установка

:::warning
**Пока не выпущен.** Сегодня загрузка недоступна ни на одной площадке. Исходный код открыт и уже сейчас доступен для сборки; см. [Сборка из исходного кода](#build-from-source) ниже.
:::

## Каналы распространения

CrocApp планируется распространять по трём каналам. Ни один из них пока не активен.

| Канал | Статус |
|---|---|
| iOS / iPadOS App Store | Планируется |
| Mac App Store | Планируется |
| Прямая загрузка для macOS (нотаризованный DMG) | Планируется |

Заметки о блокерах:

- **Нотаризация пока не реализована по-настоящему.** Скрипт нотаризации проекта сейчас останавливается на пробной проверке (`syspolicy_check distribution`) и не отправляет и не прикрепляет настоящий билет нотаризации.
- Также запланирована бета-версия в TestFlight — когда появится сборка для распространения.
- Канала через пакетный менеджер нет, и пока он не планируется.

Все функции V1 реализованы; что именно отделяет приложение от релиза, отслеживается в разделе [known issues](https://github.com/bakirgdev/CrocApp/blob/main/docs/known-issues.md) проекта, под пунктом "Blocking release".

## Сборка из исходного кода {#build-from-source}

Требуется:

- **macOS 26**
- **Xcode 26.6**
- **Go 1.26.5** или новее (`gomobile` и `gobind` устанавливаются сами при первом запуске)

```bash
git clone https://github.com/bakirgdev/CrocApp.git
cd CrocApp
scripts/build-xcframework.sh   # Go engine -> CrocKit/Croc.xcframework
open app/CrocApp.xcodeproj
```

:::warning
Чистый клон ничего не собирает, пока не существует xcframework. Бинарная цель `CrocKit` указывает на артефакт, добавленный в gitignore, поэтому `scripts/build-xcframework.sh` не является опциональным шагом.
:::

Само приложение требует **iOS 26**, **iPadOS 26** или **macOS 26** для запуска.

Полный справочник по набору инструментов, настройкам сборки и решению проблем: [`docs/BUILDING.md`](https://github.com/bakirgdev/CrocApp/blob/main/docs/BUILDING.md) на GitHub.
