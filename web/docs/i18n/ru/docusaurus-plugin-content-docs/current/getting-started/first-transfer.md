# Ваша первая передача

На главном экране CrocApp есть две кнопки: **Send** и **Receive**. Всё остальное следует из процесса в три шага:

1. Отправитель выбирает файлы, папку или фрагмент текста.
2. CrocApp генерирует кодовую фразу. Её можно произнести, отправить сообщением или показать в виде QR-кода.
3. Получатель вводит фразу, видит список файлов и принимает их.

Обе стороны выполняют PAKE по кодовой фразе, чтобы получить сеансовый ключ, поэтому фраза никогда не передаётся по сети в открытом виде, и релей её не узнаёт. Файлы шифруются с помощью кодовой фразы; релей видит только зашифрованный текст. В одной Wi-Fi сети или на разных континентах, CrocApp автоматически находит самый быстрый путь.

## Отправка

1. На главном экране нажмите **Send**.
2. В разделе **What to send** выберите **Files** или **Text**.
   - Для файлов: используйте **Add Files** или **Add Folder**, либо перетащите файлы в область для перетаскивания (macOS).
   - Для текста: введите или вставьте текст в поле.
3. При желании задайте **Custom code** (не менее 6 символов) вместо сгенерированного.
4. Нажмите **Send**.
5. CrocApp покажет **Ready to send** с кодовой фразой, кнопкой **Copy Code** и QR-кодом. Поделитесь кодом с получателем через канал, которому вы доверяете.
6. Как только получатель подключится и примет передачу, она начнётся. По завершении CrocApp покажет **Transfer complete**.

## Приём

1. На главном экране нажмите **Receive**.
2. Введите **Code phrase**, которую дал вам отправитель, вставьте её или (на iOS) нажмите **Scan QR Code**.
3. Проверьте папку назначения, показанную под полем кода; при необходимости измените её кнопкой **Change**.
4. Нажмите **Receive**.
5. CrocApp покажет **Incoming transfer** со списком файлов и общим размером. Просмотрите его, затем нажмите **Accept** или **Decline**.
6. По завершении передачи CrocApp покажет **Transfer complete** с кнопкой для открытия папки назначения (**Open in Files** на iOS, **Show in Finder** на macOS).

Подробности о каждом шаге см. в разделах [Отправка файлов](../guide/sending.md) и [Приём файлов](../guide/receiving.md).
