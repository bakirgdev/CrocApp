# Документация CrocApp

CrocApp отправляет файлы, папки и текст между двумя устройствами в любой точке мира, со сквозным шифрованием, используя короткую кодовую фразу вроде `8412-mirage-cobalt-fresco`. Не требуется ни учётной записи, ни загрузки в чужое облако, ни того, чтобы оба устройства были в одной сети.

Это графическая оболочка для [croc](https://github.com/schollz/croc) — консольного инструмента передачи файлов от Zack Scholl. CrocApp встраивает Go-библиотеку croc, а не вызывает бинарник через shell, поэтому кодовая фраза, сгенерированная в croc CLI, работает в приложении, а кодовая фраза, сгенерированная в приложении, работает в CLI.

:::note
CrocApp — неофициальное и не аффилированное приложение. Ничто здесь не подразумевает одобрения со стороны автора croc.
:::

## Как это работает, вкратце

Отправитель выбирает файлы, папку или фрагмент текста. CrocApp генерирует кодовую фразу, которую можно произнести, отправить сообщением или показать в виде QR-кода. Получатель вводит фразу, видит список файлов и принимает их. Обе стороны выполняют PAKE (аутентификацию по паролю с обменом ключами) по кодовой фразе, чтобы получить сеансовый ключ, поэтому сама фраза никогда не передаётся по сети в открытом виде, и релей её не узнаёт. Если оба устройства находятся в одной сети, CrocApp соединяется напрямую и обходит релей.

## Требования к платформе

CrocApp требует **iOS 26**, **iPadOS 26** или **macOS 26**, то есть версию `26.0` или любую более новую. Приложение работает только на платформах Apple: клиента для Windows, Linux или Android не существует.

:::warning
CrocApp пока не выпущен. Сегодня приложение недоступно для загрузки ни на одной площадке. Текущий статус и инструкции по сборке из исходного кода см. в разделе [Установка](getting-started/install.md).
:::
