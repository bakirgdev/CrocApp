Support

CrocApp is free and maintained by one person. Most answers are in the documentation. For anything else, ask in public so the next person can find the answer too.

Read first

The documentation covers installing, your first transfer, settings, and the exact security claim. Two pages answer most questions: Troubleshooting (a transfer that will not connect, guest Wi-Fi, relays) and FAQ.

Both devices need croc 11 or newer. A phone running CrocApp and a computer running an older croc command line cannot complete a transfer, and updating the older side fixes it.

Ask a question

Usage questions, setup help and ideas go to GitHub Discussions (opens in a new tab).

Report a bug

Open an issue on the issue tracker (opens in a new tab). Say which device and OS version you use, which CrocApp build you have (App Store or direct download), what you expected, and what happened. Do not paste a live code phrase or a stored-transfer link. If the same transfer fails with the croc command line, the bug is in croc itself (opens in a new tab).

Report a security problem

Do not open a public issue. Report it privately through a GitHub security advisory (opens in a new tab). If that form is not available to you, email bakirgdev@gmail.com with SECURITY in the subject. The full process is in the security policy (opens in a new tab).

Privacy

CrocApp has no accounts, analytics, ads or tracking, and history stays on the device. The privacy page lists every server it can contact.
