# assets/

Design source and marketing assets: app icon, banner, mascot, DMG background, screenshots, etc. Mostly binary; treat as source-of-truth originals, not build output.

## Layout

| Path | Purpose |
| --- | --- |
| `CrocAppIcon.icon/` | Xcode Icon Composer source (`icon.json` + layer PNGs) |
| `croc-banner.webp` | 408x271. README header banner. From official croc repository |
| `mascot.png` | 512x512 source. Never served as-is, only as a derivative |
| `dmg-background.png` | 660x400 background for the macOS DMG's Finder window |
| `screenshots/` | `<platform>-<screen>-{light,dark}.png` |

## Rules

- Screenshots are generated by `scripts/capture-screenshots.sh` from real builds. Don't hand-edit or hand-crop; re-run the script to update a screen.
- `CrocAppIcon.icon` is an Icon Composer package, not a flat image. Edit it in Xcode, not with an image editor.
- On app UI/UX/functionality changes, update screenshots to reflect new app state. If the change is minor, you can update only the affected screens. If the change is major, update all screens.
