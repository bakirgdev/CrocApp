# Screenshots

Referenced by the root `README.md` through `<picture>` elements that swap on the viewer's GitHub theme. Both files in a pair must exist or the image breaks in that theme.

| File | Shot |
|---|---|
| `mac-send-light.png` / `mac-send-dark.png` | macOS Send screen, transfer in progress, code phrase visible |
| `ios-receive-light.png` / `ios-receive-dark.png` | iOS Receive screen, incoming file list awaiting accept |
| `mac-settings-light.png` / `mac-settings-dark.png` | macOS Settings, power options |

Capture at 2x, no device frames, no personal filenames or real transfer codes. Adding or renaming a pair means editing the root `README.md`.
